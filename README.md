# TTextEditor [![License](https://img.shields.io/badge/License-MIT-yellowgreen.svg)](https://opensource.org/licenses/MIT) 

The latest release of TTextEditor control for Delphi VCL/FMX. 

The development environment is RAD Studio 13+, older Delphi versions are not supported. 

The old version can be found at https://github.com/TextEditorPro/TTextEditor-Legacy-

## Features

- Active line
  - Fill and border style
- Arabic and Hebrew support
- Border
  - Colored edges
- Code/tag/text folding
- Color themes 
  - Colors, Fonts, and FontStyles properties
  - Theme Load and Save properties 
  - JSON file/stream import
- Column selection mode
- Completion proposal
  - Snippets
- Custom key commands
- Data-aware
- Drag and drop text editing
- Highlight line
- Highlighters 
  - Highlighter Load property
  - JSON file/stream import
- HTML export (clipboard support)
- IME support
- Keyword images
- Large file support
- Left margin
  - Bookmarks
  - Custom marks
  - Line states
  - Line numbers
- Line spacing
- Macro recorder
- Matching pairs
- Minimap
  - Text or simple style
- Multi edit
- Non-blinking caret
- Partial load
- Printing
- Replace
- Right margin
- Ruler
- Scroll
  - Indicator
  - Shadow
- Search
  - Normal, extended, regular expression, and wildcard engines
  - Search map
- Simple Mode (for large files)
- Special chars
- Spell check (VCL)
- Sync edit
- Undo/redo
- Variable-width font support
- Web and email links (Ctrl+click)
- Word wrap
- Zoom

## Supports
